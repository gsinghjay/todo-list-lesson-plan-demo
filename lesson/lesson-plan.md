## 2-Week Lesson Plan: Building a Node.js Todo Application

This lesson plan outlines a 2-week curriculum for teaching students how to build a complete Todo application using Node.js, Express.js, and basic frontend JavaScript. It is structured for a classroom setting with daily objectives, concept introductions, hands-on exercises, and homework assignments.

**Target Audience:** Students with basic programming knowledge, but potentially new to web development and JavaScript.

**Technology Stack:**
*   **Backend:** Node.js, Express.js
*   **Frontend:** HTML, CSS (Bootstrap for styling), Vanilla JavaScript
*   **Data Storage:** In-memory array (for simplicity in this lesson)

**Lesson Structure:** Each day will consist of:
*   **Objective:** What students should be able to achieve by the end of the session.
*   **Concepts:** Key topics and technologies to be introduced and explained.
*   **Exercises (In-Class):** Practical coding activities to reinforce learning.
*   **Homework:** Assignments to practice concepts and prepare for the next day.

**Week 1: Backend Fundamentals and API Creation**

| **1**   | **Introduction to Web Development & Node.js** | Understand the basics of web development and the role of Node.js. | Client-side vs Server-side, Introduction to the internet, HTTP requests & responses, What is Node.js?, JavaScript runtime environment, npm & package manager. | 1.  Discuss web browsing process. 2.  Install Node.js and npm. 3.  Run a simple JavaScript program using Node.js (e.g., "Hello World"). | 1.  Research and write a short paragraph explaining the difference between frontend and backend development. 2.  Explore the npm website and find 3 popular npm packages (excluding Express). Briefly describe what they do.                                                                                                |
| **2**   | **Setting up Node.js Project & Basic Server** | Set up a Node.js project and create a basic HTTP server.      | Project setup (mkdir, cd, npm init), `package.json`, Modules and `require()`, Basic HTTP server with Node.js (`http` module),  Server listening on a port. | 1.  Create a new project directory and initialize npm. 2.  Create a `server.js` file. 3.  Write code to create a basic HTTP server that responds with "Hello Server!" on the root path (`/`). 4.  Start the server and test in a browser. | 1.  Modify the server to respond with different messages for different paths (e.g., `/hello` should return "Hello Path!"). 2.  Read about different HTTP status codes and try to use them in your server responses (e.g., 404 for a non-existent path).                                                                      |
| **3**   | **Introduction to Express.js** | Understand and use Express.js to simplify server creation. | Introduction to Express.js, Benefits of using Express, Installing Express, Creating an Express app,  Routes and middleware, `app.get()`, `app.listen()`. | 1.  Install Express.js in the project. 2.  Rewrite the HTTP server from Day 2 using Express.js. 3.  Create a route for `/` that sends "Hello Express!" as a response. 4.  Create another route for `/api/message` that sends a JSON response like `{ message: "This is an API endpoint" }`. | 1.  Explore the Express.js documentation and find out how to handle different HTTP methods (POST, PUT, DELETE). 2.  Research and list 3 commonly used Express.js middleware and explain their purpose in one sentence each.                                                               |
| **4**   | **Building API: GET Todos**   | Implement the first API endpoint to retrieve all todos.     | API design principles, RESTful API basics, GET requests,  Arrays in JavaScript (for in-memory data),  `res.json()`,  Reading data from an array. | 1.  Create an empty array `todos` to store todo items in `server.js`. 2.  Create a GET route `/api/todos`. 3.  Implement the route handler to send the `todos` array as a JSON response. 4.  Test the API endpoint using a browser or tools like curl/Postman. | 1.  Add some initial todo items (objects with `id`, `task`, `done` properties) to the `todos` array directly in `server.js`. 2.  Modify the GET `/api/todos` endpoint to filter todos based on a query parameter, e.g., `/api/todos?done=true` (optional, for more advanced students).                                                               |
| **5**   | **Building API: POST Todos**  | Implement API endpoint to add new todo items.             | POST requests, Request body, URL-encoded data, Middleware for parsing request body (`express.urlencoded()`),  Generating unique IDs (using `Date.now()` for simplicity),  Adding data to an array, `res.status(201)`. | 1.  Install and use `express.urlencoded({ extended: true })` middleware in `server.js`. 2.  Create a POST route `/api/todos`. 3.  Implement the route handler to:     a.  Extract the `task` from the request body.     b.  Create a new todo object with a unique ID, task, and `done: false`.     c.  Add the new todo to the `todos` array.     d.  Send a 201 Created status and a success message in JSON. 4.  Test the API endpoint using a form in HTML (basic form in `index.html` in `public` folder for now) or tools like Postman. | 1.  Implement basic input validation for the POST `/api/todos` endpoint to ensure that the `task` field is not empty. Return a 400 Bad Request status if it is. 2.  Research and explore other methods for generating unique IDs in JavaScript, like UUID libraries.                                                                         |
