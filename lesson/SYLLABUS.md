# Full-Stack Web Development: Building a Todo Application
**Course Duration:** 2 Weeks (10 Sessions, 2 hours each)

## Course Information
- **Course Title:** Full-Stack Web Development with Node.js
- **Course Code:** FSW-101
- **Prerequisites:** Basic programming knowledge, basic JavaScript understanding
- **Required Software:** 
  - Node.js (Latest LTS version)
  - npm (Comes with Node.js)
  - VS Code or preferred code editor
  - Modern web browser (Chrome recommended)

## Course Description
This intensive two-week course introduces students to full-stack web development through building a practical Todo application. Students will learn both backend development using Node.js and Express.js, and frontend development using HTML, CSS, and vanilla JavaScript. The course emphasizes hands-on learning and best practices in modern web development.

## Learning Objectives
By the end of this course, students will be able to:
1. Set up and configure a Node.js development environment
2. Design and implement RESTful APIs using Express.js
3. Create dynamic web interfaces using HTML, CSS, and JavaScript
4. Implement CRUD operations in a web application
5. Handle client-server communication using HTTP
6. Implement basic data persistence
7. Debug common web development issues
8. Follow web development best practices

## Course Structure

### Week 1: Backend Development
#### Day 1: Introduction to Web Development & Node.js
- Web development fundamentals
- Client-server architecture
- Node.js basics and setup
- npm package management

#### Day 2: Setting up Node.js Project & Basic Server
- Project initialization
- Basic HTTP server
- Request-response cycle
- Server configuration

#### Day 3: Introduction to Express.js
- Express.js framework
- Routing basics
- Middleware concept
- Basic error handling

#### Day 4: Building API - GET Todos
- RESTful API design
- Implementing GET endpoints
- Testing with Postman/curl
- Error handling for GET requests

#### Day 5: Building API - POST Todos
- Creating POST endpoints
- Request body handling
- Input validation
- Error handling for POST requests

### Week 2: Frontend Development & Integration
#### Day 1: Completing REST API (PUT & DELETE)
- Implementing PUT endpoints
- Implementing DELETE endpoints
- Advanced error handling
- API documentation

#### Day 2: Frontend Basics
- HTML structure
- CSS styling with Bootstrap
- JavaScript DOM manipulation
- Fetching data from API

#### Day 3: Adding New Todos
- Form handling
- POST requests from frontend
- Input validation
- User feedback

#### Day 4: Todo Management
- Updating todo status
- Deleting todos
- Dynamic UI updates
- Error handling in frontend

#### Day 5: Data Persistence
- File-based storage
- Data persistence implementation
- Final project integration
- Deployment considerations
