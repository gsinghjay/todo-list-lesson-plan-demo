# Todo Application Teaching Project

## 🎓 Overview

This repository contains a comprehensive 2-week course curriculum for teaching full-stack web development through building a Todo application. The course is designed to be beginner-friendly while covering essential concepts in modern web development.

### 📚 For Instructors

This repository provides:
- Detailed daily lesson plans
- In-class exercises and solutions
- Homework assignments
- Assessment criteria
- Teaching resources and references

#### Course Structure
- **Duration**: 2 weeks (10 sessions, 2 hours each)
- **Format**: Hands-on, project-based learning
- **Class Size**: Recommended 10-20 students
- **Teaching Style**: Interactive coding sessions with guided exercises

#### Getting Started as an Instructor
1. Review the complete curriculum in `lesson/`
2. Familiarize yourself with the final Todo application
3. Set up the development environment
4. Review daily lesson plans and exercises
5. Prepare additional examples if needed

### 🎯 For Students

Welcome to Full-Stack Web Development! This course will teach you how to build a complete web application from scratch.

#### Prerequisites
- Basic programming knowledge
- Basic understanding of JavaScript
- No prior web development experience required

#### What You'll Learn
- Backend development with Node.js
- Frontend development with HTML, CSS, and JavaScript
- RESTful API design and implementation
- Database basics and data persistence
- Modern web development best practices

#### What You'll Build
A fully functional Todo application featuring:
- User-friendly interface
- CRUD operations (Create, Read, Update, Delete)
- Data persistence
- RESTful API
- Modern styling with Bootstrap

### 🛠️ Technical Setup

#### Required Software
1. **Node.js** (LTS version)
   - Download from [nodejs.org](https://nodejs.org/)
   - Includes npm (Node Package Manager)

2. **Code Editor**
   - Recommended: Visual Studio Code
   - Download from [code.visualstudio.com](https://code.visualstudio.com/)

3. **Web Browser**
   - Recommended: Google Chrome
   - Download from [google.com/chrome](https://www.google.com/chrome/)

4. **Git**
   - Download from [git-scm.com](https://git-scm.com/)

#### Installation Steps
1. Clone this repository:
   ```bash
   git clone <repository-url>
   cd todo-application-course
   ```

2. Install dependencies:
   ```bash
   cd nodejs-todo-app
   npm install
   ```

3. Start the application:
   ```bash
   npm start
   ```

### 🎯 Learning Path

#### Week 1: Backend Development
- Day 1: Web Development & Node.js Basics
